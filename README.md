# Doro

从一张动图开始，做了一个可以转着看的 3D 小站。

**[在线玩](https://doro.yuxino.cn/)** · [备用站](https://yuxino.github.io/doro/)

Doro 虾虾、短腿狗狗，还有两只蓝色呆猫。拖动旋转、滚轮或双指缩放，也可以暂停动画，凑近看看。

支持中文 / English 切换，默认按浏览器语言／地区选择，并记住你的手动选择。

## 本地运行

```sh
pnpm install --frozen-lockfile
pnpm dev
```

构建与部署见 [开发与发布](DEVELOPMENT.md)。

猫咪造型参考 [Kit T](https://store.playstation.com/en-gb/product/EP0102-PPSA08035_00-COSTUMEAIR000016)，模型根据参考图自行制作，并非游戏原始模型。
